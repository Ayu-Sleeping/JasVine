# JasVine (Android)

一个基于 **Jetpack Compose + Kotlin** 的Android端媒体管理工具，由桌面端 [JAVM](#致谢) 移植二次开发而来，聚焦「本地媒体库 + 资源刮削 + 下载管理 + 播放器」一体化流程。

## 功能特色

- **媒体库**：宫格/列表双视图浏览、本地封面离线加载、视频详情页（演员/类型/预览图/简介）、Room 响应式自动刷新、刮削完整性自检
- **资源刮削**：多站点并发检索、字段级跨源融合（信息最全）、NFO/封面/预览图一键本地化、刮削完成通知反馈
- **下载管理**：任务队列与并发控制、暂停/恢复/取消、m3u8 全格式支持（Master Playlist + AES-128 解密）、下载完成自动刮削入库、前台服务通知
- **目录管理**：基于 SAF 的目录添加与扫描导入、删除后重扫自动从 NFO 恢复刮削信息、失效记录清理
- **播放器**：ExoPlayer 硬解优先、手势控制（亮度/音量/进度）
- **应用自动更新**：基于 GitHub Releases 检查新版本、Markdown 更新日志渲染、静默后台下载并引导安装

## 下载与安装

前往本仓库的 [Releases](https://github.com/AyU-Sleeping/JasVine/releases) 页面，下载最新版本的 APK 附件


> 应用内置**自动更新**：启动时会自动检查新版本（可在「设置 → 关于」中关闭），发现新版本后弹窗提示，支持应用内下载与安装。也可在「设置 → 关于 → 检查更新」中手动检查。
